# CareerMate — Exact Thesis-Style VS Code Demo

This runnable Gradio project mirrors the Chapter Four CareerMate interface and module structure as closely as practical in a local academic demo.

## Run in VS Code
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run: `pip install -r requirements.txt`
4. Run: `python app.py`
5. The browser opens automatically at the local Gradio address (normally http://127.0.0.1:7860).

## Modules
Dashboard, Student Profile, Conversational Interaction, Result Upload, Ranked Recommendations, Institution Comparison, Career Explorer, Vocational Pathways, and Session Summary/Feedback.

## Note
The bundled admission/cost records are demonstration data for the interface. Replace them with verified current institutional data before presenting them as current facts.
